How to create a strong password

Last updated: 24 November 2026

Length beats complexity

The strength of a random password depends on how many possible passwords there are. That number grows with every character you add. Each extra character multiplies the possibilities by the size of the character set, so a longer password is much harder to guess than a shorter one with more symbols.

Strength in bits = length x log2(number of possible characters)

Example: 8 lowercase letters give 8 x log2(26) = about 38 bits. 16 characters drawn from a pool of 85 (letters, numbers and symbols) give 16 x log2(85) = about 102 bits.

Random is better than clever

People tend to choose predictable passwords: names, dates, keyboard patterns, or a word with a number on the end. Attackers try these first. A password produced by a random generator has no pattern to guess.

Use a different password for every account

If one website is breached, attackers try the same email and password on other sites. A unique password limits the damage to a single account.

Store passwords in a password manager

Nobody can remember dozens of long random passwords. A reputable password manager stores them for you, so you only need to remember one strong master password. Do not keep passwords in a plain text file or in your email.

Turn on two-step verification

Two-step verification asks for a second proof, such as a code from an authenticator app, in addition to your password. It protects the account even if the password is stolen. Prefer an authenticator app or a security key over text messages where the service offers a choice.

Quick checklist

  • Use 16 or more characters for important accounts.
  • Let a generator choose the characters.
  • Never reuse a password.
  • Use a password manager.
  • Enable two-step verification.
  • Change a password immediately if you think it has been exposed.

Frequently asked questions

Is it safe to use an online password generator?

It is safe when the password is created in your browser and not sent anywhere, as this tool does. Never use a generator that asks you to submit your own password.

How often should I change passwords?

There is no need to change a strong, unique password on a schedule. Change it if the service reports a breach or you suspect it has been exposed.
