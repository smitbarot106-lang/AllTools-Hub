About the JSON Formatter and Validator

The JSON formatter and validator makes JSON easy to read, shrinks it for production and checks that it is valid. Paste your data, choose Format, Minify or Validate only, and copy or download the result. If the JSON is broken, the tool shows the error message from the browser's JSON parser.

JSON is the most common format for sending data between websites and apps, but a single missing comma or quote breaks it. Working with encoded data as well? See the Base64 Encoder and Decoder and URL Encoder and Decoder.

How to use it

  1. Paste your JSON into the box.
  2. Choose Format (easy to read), Minify (smallest size) or Validate only.
  3. Click Run.
  4. Copy or download the result.

How it works

  • Format: the data is parsed and written back with 2 spaces, 4 spaces or a tab for each level of nesting.
  • Minify: the data is parsed and written back with no extra spaces or line breaks.
  • Validate: the data is parsed and the tool reports whether it is valid and what its top-level type is (object, array, string, number, boolean or null).

Worked example

The input {"name":"Asha","age":30} is formatted with each property on its own indented line. The formatted version is 33 characters long, compared with 24 characters before.

Common uses

  • Reading an API response that arrives on one line.
  • Finding a syntax error in a configuration file.
  • Minifying JSON to reduce its size.
  • Checking data before you send it to a service.

Limitations

  • Only strict JSON is accepted. Comments, trailing commas and single-quoted strings are not valid JSON and will be rejected.
  • Very large files (many megabytes) can be slow in a browser tab.
  • Large numbers beyond the range JavaScript can represent exactly may lose precision when the data is re-written.

Frequently asked questions

Why does my JSON say it is invalid?

Common causes are a trailing comma, single quotes instead of double quotes, unquoted property names, or a missing bracket. The error message points to the position of the problem.

Is my JSON uploaded?

No. It is parsed in your browser and never leaves your device.

What is the difference between format and minify?

Format adds indentation for people to read. Minify removes all unnecessary spaces to make the data smaller.

Does formatting change my data?

No, apart from whitespace. The order of properties is kept.
