About the Password Generator

The password generator creates a random password from the character types you choose, using your browser's secure random number generator. Nothing is sent to a server and nothing is saved, so the password exists only on your screen until you copy it.

Length matters more than complexity: every extra character multiplies the number of possible passwords. Read the guide How to create a strong password for practical advice. If you need a unique identifier instead of a password, see the UUID Generator.

How to use it

  1. Choose the password length. 16 or more is a good choice.
  2. Tick the kinds of characters you want.
  3. Click Generate password.
  4. Click Copy and paste it into your password manager or account form.

How it works

  • Strength in bits = length x log2(number of possible characters).
  • With all four character types the pool is 85 characters, so each character adds about 6.4 bits. A 16-character password is about 102 bits.
  • The tool labels the result Weak below 40 bits, Fair below 60, Good below 80 and Strong from 80 upwards. These labels are a guide, not a guarantee.

Worked example

A password that uses a pool of 26 lowercase letters has about 4.7 bits per character, so 8 characters give about 38 bits (Weak). Using all four character types and 16 characters gives about 102 bits (Strong).

Common uses

  • Creating a new password for an account.
  • Generating a master password or a Wi-Fi key.
  • Making temporary passwords for testing.

Limitations

  • A random password is only as safe as the place you keep it. Use a trusted password manager.
  • Some websites reject certain symbols or limit the length. Untick symbols or shorten the length if a site refuses the result.
  • The strength estimate assumes the password is random and used on one site only.

Frequently asked questions

Is the generated password sent to your server?

No. It is created in your browser and is never transmitted or stored.

How long should a password be?

Sixteen characters or more is a good choice for important accounts, with a different password for every account.

Why skip look-alike characters?

Characters like 0, O, 1, l and I are easy to confuse when you have to type a password by hand.

Is a generated password better than one I make up?

Usually yes. People tend to pick predictable patterns, while a generator picks characters at random.
