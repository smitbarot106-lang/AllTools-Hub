About the URL Encoder and Decoder

Web addresses can only contain a limited set of characters. Spaces, ampersands and many symbols have to be written as percent codes such as %20. This tool encodes text so it is safe to place in a web address, and decodes percent codes back into readable text.

Pick "Encode a piece of text" for a single value such as a search term, "Encode a full web address" to keep characters like : / ? & = in place, or "Decode" to reverse the process. Working with API data? The JSON Formatter and Validator and Base64 Encoder and Decoder may also help.

How to use it

  1. Paste your text or web address.
  2. Choose what you want to do.
  3. Click Convert.
  4. Copy the result.

How it works

  • Encoding a piece of text (encodeURIComponent) converts every character except letters, numbers and - _ . ! ~ * ' ( ) into %XX codes, where XX is the character's UTF-8 value in hexadecimal.
  • Encoding a full address (encodeURI) leaves the address punctuation characters, such as : / ? # & =, unchanged.

Worked example

The text "hello world & friends" encodes to hello%20world%20%26%20friends. The space becomes %20 and the ampersand becomes %26.

Common uses

  • Building a query string by hand.
  • Reading an encoded link that is full of % codes.
  • Making a link that contains a space or an ampersand work correctly.

Limitations

  • Encoding a complete address as a single piece of text will also encode its slashes and colons, which breaks the link. Use the full-address option for that.
  • Decoding fails if a % is not followed by two valid hexadecimal characters.

Frequently asked questions

What does %20 mean?

It is the encoded form of a space character.

What is the difference between the two encode options?

The piece-of-text option encodes everything that is not a letter or number, which is correct for a value inside a query string. The full-address option leaves the address punctuation alone.

Why does decoding fail?

Usually because a % sign is not followed by two valid characters, for example a plain "100%" typed in the text.

Is anything sent to a server?

No. The conversion runs in your browser.
