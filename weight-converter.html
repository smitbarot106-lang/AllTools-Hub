About the Weight Converter

The weight converter changes a mass from one unit to another: milligrams, grams, kilograms, tonnes, ounces, pounds and stone. Enter a value, choose the units, and the same weight is shown in every other unit.

Use it for cooking, shipping, gym weights, travel baggage allowances or body weight. For a health check from weight and height, try the BMI Calculator. To convert distance instead, use the Length Converter.

How to use it

  1. Type the number you want to convert.
  2. Choose the unit you start with in "From".
  3. Choose the unit you want in "To".
  4. Click Convert. The result and the same value in all other units appear below.

How it works

  • Each unit is defined in kilograms, and conversions go through kilograms: result = value x (kg per from-unit) / (kg per to-unit).
  • 1 pound = 0.45359237 kg exactly, 1 ounce = 0.028349523125 kg, and 1 stone = 6.35029318 kg (14 pounds).

Worked example

70 kilograms = 70 / 0.45359237 = about 154.32 pounds.

Common uses

  • Converting recipe quantities between grams and ounces.
  • Checking baggage and parcel weight limits.
  • Converting body weight between kilograms, pounds and stone.

Limitations

  • This tool converts mass. It does not convert volume (such as cups to grams), because that depends on the ingredient.
  • Results are shown to 10 significant digits.

Frequently asked questions

How many pounds are in a kilogram?

One kilogram is about 2.20462 pounds.

How many pounds are in a stone?

One stone is 14 pounds.

Is a tonne the same as a ton?

A tonne (metric ton) is 1,000 kg. The US ton is 2,000 pounds, which is not the same and is not included here.

Can I convert cups to grams?

No. That needs the density of the ingredient. This tool only converts units of weight.
