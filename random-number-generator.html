About the Random Number Generator

The random number generator picks one or many whole numbers between a minimum and a maximum. You can ask for numbers that never repeat, which is useful for draws and for choosing winners without picking anyone twice.

Numbers come from your browser's secure random generator (crypto.getRandomValues), and the code removes the small bias that a simple modulo would introduce, so every number in the range has an equal chance. For random IDs instead of numbers, see the UUID Generator.

How to use it

  1. Enter the smallest and the largest number.
  2. Enter how many numbers you want.
  3. Tick "No repeats" if every number must be different.
  4. Click Generate.

How it works

  • Each number is chosen uniformly from min to max, so the range contains max - min + 1 possible values.
  • With "No repeats" ticked, numbers that have already been picked are skipped, so you cannot ask for more numbers than the range contains.

Common uses

  • Picking a winner for a giveaway or classroom draw.
  • Rolling dice for a board game (1 to 6).
  • Choosing a random order or sample.
  • Generating test data.

Limitations

  • Only whole numbers are generated. Decimals are not supported.
  • The range is limited to -1,000,000,000 to 1,000,000,000 and up to 1,000 numbers at a time.
  • Do not use the tool for regulated lotteries or gambling.

Frequently asked questions

Is the generator really random?

It uses your browser's cryptographically secure random source, which is suitable for draws and games.

How do I draw several different winners?

Set the range to the number of entries, ask for the number of winners and tick "No repeats".

Can I pick a number between 1 and 6 like a die?

Yes. Set the smallest number to 1, the largest to 6, and how many numbers to 1.

Why does it say there are not enough numbers?

With "No repeats" on, you cannot ask for more numbers than the range contains.
