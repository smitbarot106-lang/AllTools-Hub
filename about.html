About AllTools Hub

AllTools Hub is a collection of free online tools for everyday jobs: counting words, working out a loan, formatting data, converting units and more. Each tool is built to be clear for a first-time visitor.

How we work

  • Simple. Every tool explains what it does, what to enter and what you will get.
  • Private. Our tools run in your browser. The text and numbers you enter are not uploaded to our servers.
  • Honest. We only list tools that work. We do not add a tool just to make the list longer.
  • Free. You do not need an account to use any tool.

What is available today

There are currently 19 tools in 5 categories: text tools, calculators, developer tools, unit converters and other everyday tools. We plan to add more over time, and we test each one before it is published.

About the design

The look of the site is built on the golden ratio (about 1.618) and the Fibonacci numbers. Columns split in that ratio, type sizes step by it, and spacing follows the Fibonacci sequence.
