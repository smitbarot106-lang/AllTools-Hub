About the UUID Generator

A UUID (Universally Unique Identifier) is a 128-bit ID written as 36 characters, such as 123e4567-e89b-42d3-a456-426614174000. Version 4 UUIDs are generated from random numbers, so the chance of two being the same is extremely small, which makes them useful as database keys, file names and tracking IDs without a central counter.

This tool makes up to 100 UUIDs at a time using your browser's secure random generator. Need a password rather than an ID? Use the Password Generator. For a plain random number, try the Random Number Generator.

How to use it

  1. Enter how many UUIDs you need (1 to 100).
  2. Tick the box if you want capital letters.
  3. Click Generate.
  4. Copy or download the list.

How it works

  • A version 4 UUID has 122 random bits. The other 6 bits are fixed to mark the version (the "4" at the start of the third group) and the variant (the first character of the fourth group is 8, 9, a or b).
  • The format is 8-4-4-4-12 hexadecimal digits separated by dashes.

Common uses

  • Creating primary keys for database records.
  • Naming uploaded files so they never clash.
  • Creating test data.
  • Labelling events, sessions and requests in logs.

Limitations

  • A UUID is an identifier, not a secret. Do not use it as a password or access token.
  • Version 4 UUIDs are not sortable by time. Other versions exist for that purpose.
  • Uniqueness is statistical, not absolute, though collisions are practically impossible in normal use.

Frequently asked questions

What is a UUID version 4?

A UUID made from random numbers. It is the most widely used type.

Can two UUIDs be the same?

It is theoretically possible but so unlikely that systems treat UUIDs as unique.

What is the difference between a UUID and a GUID?

GUID is the name Microsoft uses for the same kind of identifier.

Are the UUIDs stored anywhere?

No. They are created in your browser and disappear when you leave the page.
