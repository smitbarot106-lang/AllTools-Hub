About the Base64 Encoder and Decoder

Base64 is a way of writing data using only letters, numbers and a few symbols, so that it can travel safely through systems built for plain text, such as emails, web addresses and some APIs. This tool encodes text to Base64 or decodes Base64 back into text, with full support for accented letters and emoji (UTF-8).

Base64 is an encoding, not encryption: anyone can decode it. If your data is part of a web address, the URL Encoder and Decoder may be what you need. To check structured data, try the JSON Formatter and Validator.

How to use it

  1. Paste your text or your Base64 code.
  2. Choose Encode (text to Base64) or Decode (Base64 to text).
  3. Click Convert.
  4. Copy the result.

How it works

  • Base64 takes the data 3 bytes (24 bits) at a time and writes it as four characters from a 64-character alphabet (A-Z, a-z, 0-9, + and /).
  • If the data does not divide into groups of three, one or two = characters are added as padding.
  • Encoded text is about one third larger than the original.

Worked example

The text "Hello, world!" encodes to SGVsbG8sIHdvcmxkIQ==. Decoding that string returns the original text.

Common uses

  • Reading the contents of a Base64 string from an API or email header.
  • Preparing text to be placed in a URL, JSON field or configuration value.
  • Debugging tokens and data URLs.

Limitations

  • Base64 is not encryption and offers no protection. Never use it to hide passwords or secrets.
  • Only text is supported. Decoding a Base64 file or image will fail with a message, because the result is not readable text.
  • The tool accepts URL-safe Base64 (using - and _), but does not add line breaks.

Frequently asked questions

Is Base64 secure?

No. It only changes how data is written. Anyone can reverse it, so it provides no confidentiality.

Why does decoding give an error?

The input may contain characters Base64 does not use, or the decoded data may be a file or an image rather than text.

Why does the output end with = signs?

They are padding that fills the last group of characters.

Does it support emoji and non-English letters?

Yes. Text is converted with UTF-8 before encoding.
